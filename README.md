# MyEnglishAPP 📱🇬🇧

O **MyEnglishAPP** é um aplicativo móvel desenvolvido em Python (utilizando a biblioteca Flet) e integrado com uma base de dados local SQLite. Foi concebido especificamente para funcionar como um compêndio dinâmico e inteligente para estudantes de inglês, ajudando a memorizar, testar e organizar vocabulário novo de forma interativa.

---

## 🚀 Funcionalidades Principais

* 📝 **Novo (Registo de Palavras):** Permite inserir uma nova palavra em inglês e o respetivo significado, com a opção opcional de carregar uma imagem associada para reforçar a aprendizagem visual através de contextos e ações.
* 🧠 **Praticar (Randomizador / Quiz):** Ferramenta de treino interativa que sorteia aleatoriamente as palavras guardadas. O utilizador escreve a tradução e o aplicativo valida a resposta, informando se está correta ou incorreta (revelando a resposta certa em caso de erro) e mostrando a imagem associada.
* 📚 **Biblioteca (Pesquisa e Gestão):** Repositório completo que reúne todas as palavras e imagens guardadas, equipado com uma barra de pesquisa rápida e opções para editar ou eliminar registos futuramente.

---

## 🛠️ Tecnologias Utilizadas

* **Python** (Lógica principal do aplicativo)
* **Flet** (Framework de interface gráfica baseado em Flutter)
* **SQLite3** (Base de dados local)
